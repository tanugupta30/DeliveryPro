# DeliveryPro

DeliveryPro is a responsive, browser-based food delivery operations dashboard. It provides a demo interface for reviewing delivery activity and managing sample orders, restaurants, delivery partners, customers, payments, and reviews.

## Features

- Delivery overview dashboard with order statistics, revenue chart, and recent orders
- Create, edit, search, filter, and delete demo orders
- Restaurant, delivery partner, and customer management
- Order status progression, partner assignment, and a delivery tracking view
- Sample payment records, simulated refunds, and review management
- CSV export for supported data lists
- Responsive navigation and layouts for desktop and mobile screens
- Browser `localStorage` persistence for demo data

## Run locally

No package installation or build step is required.

1. Download or clone this project.
2. Open `index.html` in a modern browser.
3. Use the sidebar to explore the dashboard and demo management pages.

The application is implemented with plain HTML, CSS, and JavaScript. Sample data and changes are stored in the current browser, under the `deliverypro-data-v1` local storage key.

## Demo limitations

This project is a front-end demonstration. It does not connect to a backend or provide real user authentication, live GPS tracking, or payment gateway processing. Order tracking, account actions, payments, and refunds are simulated in the browser.

## Project files

- `index.html` — application shell and shared modal
- `style.css` — dashboard styling and responsive layouts
- `script.js` — sample data, page rendering, and demo interactions
